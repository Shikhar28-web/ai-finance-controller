— coverage

Share of records reaching a terminal state without a human. It is this low by design: only VERIFIED and EXPLAINED auto-reconcile, and a duplicated bank credit is fully attributable yet still routed to a person — attributing a gap is not the same as the gap being benign.

—

Classification accuracy across all five states.

This is the expected result here, not a good one.

  1. Generator and classifier share the same fee arithmetic — single-cause faults are correct by construction.
  2. The decomposer's cause list is the same closed set as the generator's fault list — there is no cause it can fail to recognise.
  3. ~64% of scored units carry a fault, against roughly 5% in a real merchant file — not comparable to production accuracy.
  4. The answer key's independence is unverifiable — the decision cascade was designed before the key was written.
